# WorldShot Log 紹介サイト用 機能整理 v2.5.1

以下は、GitHub Pages などの紹介サイトへ反映するためのコピペ用整理文です。

## アプリ概要

WorldShot Log は、VRChat のスクリーンショットを整理し、見返し、投稿しやすく整えるための Windows 向けデスクトップアプリです。

日付やワールドごとの写真管理に加えて、画像補正、切り抜き、AI被写体選択、背景透過保存、目隠し加工、テキスト追加、画像オーバーレイなどの編集機能を備えています。元画像は上書きせず、加工後の画像を別名保存できます。

> WorldShot Log は VRChat Inc. 公式のアプリではありません。

## できること

### VRChatスクリーンショットの整理

- VRChat のスクリーンショットをドラッグ&ドロップで取り込めます。
- 登録フォルダを再走査し、追加された写真を取り込めます。
- 年、月、日付、ワールドごとに写真を確認できます。
- お気に入り、向き、ラベル、World名で写真を絞り込めます。
- 複数選択、Shift範囲選択、ドラッグ選択、キーボード移動に対応しています。

### 写真の詳細確認

- 写真をカード形式で閲覧できます。
- 写真詳細モーダルで画像を大きく確認できます。
- 前後の写真へ移動できます。
- 元画像や保存先フォルダを開けます。
- VRChatページを開けます。
- お気に入り、ラベル、メモ、World名、World URL を管理できます。

### ワールド情報の補助管理

- 写真から World ID を扱いやすく整理できます。
- 取り込み後に World 情報を取得できます。
- 同じ World ID の写真では取得済み情報を再利用できます。
- ワールド名、説明文、タグ、World URL を確認できます。

### アプリ内画像編集

- 写真詳細から画像編集画面を開けます。
- 元画像を上書きせず、加工後の画像を別名保存できます。
- 明るさ、露出、コントラスト、ハイライト、シャドウ、ホワイト、ブラックを調整できます。
- 色温度、色合い、彩度、自然な彩度を調整できます。
- 明瞭度、テクスチャ、フェード、粒子、ビネットを調整できます。
- スマート自動補正、学習補正、補正の強さ調整を利用できます。
- RGB / HSV のトーンカーブとヒストグラム表示に対応しています。
- プリセット適用とユーザープリセット保存に対応しています。
- Undo / Redo、編集前後の比較表示、各セクションのリセットに対応しています。

### 切り抜きと構図調整

- オリジナル、1:1、16:9、9:16、5:4、4:5、3:2、2:3 の比率で切り抜けます。
- VRCギャラリー用、絵文字・ステッカー用、アバターサムネイルのトリミングプリセットを利用できます。
- 足りない部分を透過として残したまま、正方形キャンバスに配置できます。
- 解像度を指定するプリセットは、保存時に指定サイズへリサイズされます。
- ズーム、左右位置、上下位置を調整できます。
- 90度回転、自由回転、左右反転、上下反転に対応しています。
- ルーラーと三分割グリッドを表示して、構図を確認しながら編集できます。

### AI被写体選択

- 軽量AIによるローカル被写体マスク生成に対応しています。
- 標準AI withoutBG Snap、高精度AI withoutBG Focus OSS は必要な場合のみ初回ダウンロードできます。
- AI処理はPC内で実行され、画像はAI処理のために外部サーバーへ送信しません。
- 生成した被写体マスクを、補正、ぼかし、テキスト、画像オーバーレイの適用範囲に利用できます。
- ブラシでマスクを手動修正できます。
- ブラシ濃度の調整やスポイトにより、自然な境界へ調整できます。
- Canvas上で拡大しながら細部のマスクを編集できます。
- 被写体マスクを使って背景透過PNGを保存できます。

### 画像オーバーレイ

- 透過画像などを素材として管理し、写真に重ねられます。
- 複数の画像オーバーレイをレイヤーとして配置できます。
- 透明度、合成方法、適用範囲、前後順、サイズを調整できます。
- 追加時は元素材の比率を保って配置されます。
- ルーラーやグリッドへ軽く吸い付くように調整できます。

### ぼかし・目隠し加工

- 画像全体をぼかせます。
- 放射ぼかしで、中心を残しつつ周辺をぼかせます。
- ぼかし、モザイク、塗りつぶしによる目隠し加工に対応しています。
- 四角、円、フリーハンドで範囲選択できます。
- 選択範囲は確定前に移動、拡大縮小、回転できます。
- ユーザー名、チャット欄、UI、個人情報などを隠す用途に使えます。

### テキスト追加

- 画像上に複数のテキストを追加できます。
- 文字サイズ、フォント、太さ、色を変更できます。
- 縁取り、影、発光などの装飾を調整できます。
- 文字間隔を調整できます。
- テキストの移動、回転に対応しています。
- 日本語向けフォントや装飾フォントを利用できます。
- フォント選択時に各フォントの見た目をプレビューできます。
- 最近使ったフォントを選びやすく表示できます。

### 表示言語

- 日本語、英語、韓国語の表示に対応しています。
- 設定画面から表示言語を変更できます。

### データ管理

- サムネイル再生成に対応しています。
- 欠損ファイル、欠損サムネイル、World情報未取得の確認ができます。
- バックアップ作成とバックアップからの復元に対応しています。
- CSV / JSON エクスポートに対応しています。
- 追加ダウンロードしたAIモデルや画像オーバーレイ素材は、アプリ内から削除できます。
- アプリ内アンインストール導線を備えています。

## 想定用途

- VRChatスクリーンショットの整理
- 撮影したワールドの振り返り
- X投稿用の画像調整
- Booth掲載用の画像準備
- サムネイル用のトリミング
- チャット欄やユーザー名を隠した投稿画像の作成
- VRCギャラリーや絵文字・ステッカー向けの正方形画像作成
- 被写体だけを残した背景透過画像の作成

## 強み

- VRChatスクリーンショット管理に特化しています。
- 整理、閲覧、簡易レタッチ、投稿準備をひとつの流れで行えます。
- 元画像を破壊せず、加工後の画像を別名保存できます。
- 投稿や掲載に使いやすい編集機能へ絞っています。
- AI被写体選択はローカル実行で、画像をAI処理のために外部サーバーへ送信しません。
- 大量の写真を扱うことを前提に、一覧表示や画像編集の操作感を調整しています。

## サイト向け短文

WorldShot Log は、VRChatスクリーンショットを整理し、見返し、投稿しやすく整えるためのWindows向けアプリです。日付やワールドごとの写真管理に加えて、明るさ補正、トーンカーブ、切り抜き、AI被写体選択、背景透過保存、目隠し加工、テキスト追加、画像オーバーレイなどの編集機能を備えています。元画像は上書きせず、加工後の画像を別名保存できるため、大切なスクリーンショットを残したまま投稿用の画像を作成できます。

## サイト向けキャッチコピー案

- VRChatスクリーンショットを、整理から投稿準備まで。
- 思い出を見返しやすく、投稿しやすく。
- VRChat写真の整理と軽いレタッチを、ひとつのアプリで。
- ワールドの思い出を残す、整える、届ける。
- 被写体を活かして、投稿用の一枚へ。
