# WorldShot Log 紹介サイト用 機能整理 v2.0.0

以下は、GitHub Pages などで紹介サイトを作るためのコピペ用整理文です。

## アプリ概要

WorldShot Log は、VRChat のスクリーンショットを整理、閲覧、補助管理するための Windows 向け Electron アプリです。

撮影した画像を日付やワールドごとに見返しやすくし、撮影場所の確認、メモ、投稿準備、簡単な画像加工までをひとつのアプリ内で行えます。

## できること

### VRChatスクリーンショットの整理

- VRChat のスクリーンショットを一覧表示できます。
- 撮影日ごとに写真を確認できます。
- ワールドごとに写真を確認できます。
- サイドメニューから年月や日付へすばやく移動できます。
- 写真の解像度ラベルを表示できます。
- 大量の写真でも段階的に表示し、一覧の体感速度を保ちます。

### 写真の詳細確認

- 写真をカード形式で閲覧できます。
- 写真詳細モーダルで画像を大きく確認できます。
- ファイル名、保存先、撮影日、ワールド情報などを確認できます。
- 保存先フォルダを開けます。
- 対応している場合はVRChat関連の情報へアクセスできます。

### ワールド情報の補助管理

- スクリーンショットに紐づくワールド情報を管理できます。
- World ID やワールド名をもとに写真を整理しやすくします。
- ワールド別の写真一覧から、同じワールドで撮影した写真を振り返れます。

### メモと補助情報

- 写真にメモを残せます。
- プリント写真など、補助的な情報を写真カード上で判別しやすくします。
- 写真管理に必要な情報を、画像閲覧の流れの中で扱えます。

### アプリ内画像編集

- 写真詳細から画像編集画面を開けます。
- 元画像を上書きせず、加工後の画像を別名で保存できます。
- VRChatスクリーンショットを投稿や掲載に使いやすい見た目へ整えられます。

### 基本補正

- 明るさ、露出、コントラストを調整できます。
- ハイライト、シャドウ、ホワイト、ブラックを調整できます。
- 色温度、色合い、彩度、自然な彩度を調整できます。
- 明瞭度、テクスチャ、フェード、粒子、ビネットを調整できます。
- スライダーで細かく調整でき、各項目を個別にリセットできます。

### スマート自動補正

- 画像のヒストグラムをもとに、明るさや白飛びを考慮したスマート自動補正を利用できます。
- 補正の強さをスライダーで調整できます。
- 明るい画像、暗い画像、白飛びしやすい画像でも破綻しにくいように調整されています。
- 学習補正により、ユーザーの調整傾向を反映した補正も利用できます。

### トーンカーブ

- RGB全体、R、G、B のカーブを調整できます。
- HSV全体、H、S、V のカーブを調整できます。
- 5点カーブで細かく調整できます。
- カーブの背景にヒストグラムを表示し、画像の明暗分布を見ながら調整できます。

### プリセット

- ワンクリックで雰囲気を変えられるプリセットを利用できます。
- 夜景、ネオン、ふんわり、フィルム、高コントラスト、青系、ピンク系などのプリセットがあります。
- 自分で調整した内容に名前を付けて、ユーザープリセットとして保存できます。
- 作成したプリセットは削除できます。

### 切り抜きと構図調整

- オリジナル、1:1、16:9、9:16、5:4、4:5、3:2、2:3 の比率で切り抜けます。
- VRCギャラリー用、絵文字・ステッカー用の正方形トリミングプリセットを利用できます。
- 足りない部分を透過として残したまま、正方形キャンバスに配置できます。
- ズーム、左右位置、上下位置を調整できます。
- 90度回転、自由回転、左右反転、上下反転に対応しています。
- ルーラーと三分割グリッドを表示して、構図を確認しながら編集できます。

### ぼかし

- 画像全体をぼかせます。
- 放射ぼかしで、中心は残しつつ周辺をぼかすような加工ができます。
- 画像上の円を直接操作して、ぼかしの範囲やなだらかさを調整できます。

### 目隠し加工

- ユーザー名、チャット欄、UI、個人情報などを隠せます。
- ぼかし、モザイク、塗りつぶしを選べます。
- 四角、円、フリーハンドで範囲選択できます。
- 選択範囲は確定前に移動、拡大縮小、回転できます。
- 円形の範囲は画像外にも広げられるため、半円や扇形のような目隠しにも使えます。

### テキスト追加

- 画像上に複数のテキストを追加できます。
- 文字サイズ、フォント、太さ、色を変更できます。
- 縁取り、縁の種類、縁内の透過、縁の色を調整できます。
- 文字間隔を調整できます。
- テキストの位置、サイズ、回転を画像上で調整できます。
- よく使う日本語フォントや装飾フォントを利用できます。
- 最近使ったフォントを選びやすく表示できます。

### 編集を支える操作

- Undo / Redo に対応しています。
- 編集前後の比較表示ができます。
- 各セクションのリセットや全体リセットができます。
- スクロールやドラッグで、画像を直感的に拡大、縮小、移動できます。

## 想定用途

- VRChatスクリーンショットの整理
- 撮影したワールドの振り返り
- X投稿用の画像調整
- Booth掲載用の画像準備
- サムネイル用のトリミング
- チャット欄やユーザー名を隠した投稿画像の作成
- ギャラリーや絵文字・ステッカー向けの正方形画像作成

## 強み

- VRChatスクリーンショット管理に特化しています。
- 整理、閲覧、簡易レタッチ、投稿準備をひとつの流れで行えます。
- 元画像を破壊せず、加工後の画像を別名保存できます。
- 本格的すぎる編集ソフトではなく、スクリーンショット投稿に必要な加工へ絞っています。
- 大量の写真を扱うことを前提に、一覧表示や画像編集の操作感を調整しています。

## サイト向け短文

WorldShot Log は、VRChatスクリーンショットを整理し、見返し、投稿しやすく整えるためのWindows向けアプリです。日付やワールドごとの写真管理に加えて、明るさ補正、トーンカーブ、切り抜き、目隠し加工、テキスト追加などの編集機能を備えています。元画像は上書きせず、加工後の画像を別名保存できるため、大切なスクリーンショットを残したまま投稿用の画像を作成できます。

## サイト向けキャッチコピー案

- VRChatスクリーンショットを、整理から投稿準備まで。
- 思い出を見返しやすく、投稿しやすく。
- VRChat写真の整理と軽いレタッチを、ひとつのアプリで。
- ワールドの思い出を残す、整える、届ける。
