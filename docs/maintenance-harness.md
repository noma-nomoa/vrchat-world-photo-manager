**保守用の検証ハーネス（2026-09-10）**

リリース済み機能の変更を検出する入口を `npm run check` にまとめた。Windowsの開発環境で依存関係をインストール済みの状態から実行する。

```powershell
npm.cmd run check
```

構文、単体・固定画像演算、翻訳、実Electronの一覧・検索・サムネイル、レタッチ、DB・復元、更新失敗からの再試行の順に19段階で検証する。配布パッケージのビルドや公開はこのコマンドに含まれない。

変更箇所を絞って確認するときは以下を使う。

| コマンド | 対象 |
| --- | --- |
| `npm.cmd run check -- --suite=unit` | 全JavaScriptの構文、独立部品、Windows確認用ランチャー、固定画像演算、翻訳監査 |
| `npm.cmd run smoke:library` | 実画面の一覧・検索・各フィルター・並び順・選択・年月切替、サムネイル移行・生成・安全な保存先 |
| `npm.cmd run smoke:retouch` | マスク・保存・画像素材の非同期競合、素材読込失敗、実Worker、PNG/JPEG/WebP保存、座標、ブラシ、プリセット |
| `npm.cmd run smoke:data-safety` | 旧DB互換、不正バックアップ拒否、実復元、World情報の保全 |
| `npm.cmd run check -- --suite=application` | 更新の同期例外・非同期失敗後の再試行。実ネットワークやインストールは行わない |

`smoke:retouch` と `smoke:data-safety` も同じ実行ハーネスを使う。個々の `smoke:*` は従来どおり単独実行できる。画像処理の式を変えるときは、現行コードから期待値を作り直して一致させず、固定baselineとの相違を調べる。

**失敗を見逃さないための動作**

- 各チェックを順番に起動し、最初の失敗で後続を停止する。成功した項目だけで全体成功を表示しない。
- `out/regression-checks/<日時-PID>/` にチェック別のログと `result.json` を残す。開始時から `ok: false` とし、各結果を追記、すべて完了した場合だけ成功にする。
- `src`・`scripts`・`resources`・`img` とパッケージ・Forge設定のSHA-256を開始時に保存し、終了時にも比較する。検証中に入力が変わった結果は成功扱いにしない。確認用ビルドはこの記録を照合し、古いソース・一部の検証だけの結果を拒否する。
- 子プロセスの標準出力・標準エラーはファイルへ直接接続する。起動元ターミナルが閉じても、Electronが消失したパイプへログを書いてEPIPEになる経路を避ける。
- 各チェックの制限時間は通常180秒、2モードの保存検証は360秒。タイムアウトやCtrl+Cでは、そのチェックのPIDと子孫だけを終了する。Electron全体を名前で一括終了しない。
- 起動失敗、非ゼロ終了、時間超過、中断、終了処理の失敗はいずれも成功として扱わない。中断されたチェックや未実行の後続は検証済みと数えない。

ハーネス自体も、ログの接続先、非ゼロ終了、起動失敗、タイムアウト、子孫プロセスの終了、中断、未実行項目の停止を実プロセスで検証する。通常の実行結果は既存スモークの詳細JSON・画像と合わせて読む。

Windows確認用ランチャーは実際の `cmd.exe` と Windows PowerShell 5.1 を通して検証する。日本語と空白を含むパス・UTF-8の設定JSON・環境変数の隔離と復元・ログ・異常終了・未検証候補の拒否を、小さな代替EXEで確認する。このテストにはWindows標準の.NET Framework C#コンパイラを使用し、普段のアプリやデータは開かない。配布アプリを直接起動するスモークだけでは、ユーザーに渡すランチャー経路の検証にはならない。

配布候補の `smoke-review-profile.js` は、撮影に必要な描画フレームを確認するためテスト用ウィンドウを表示する。実行中はそのウィンドウを最小化しない。描画待ちは5秒、個々の画面評価は10秒までとし、失敗した式とページの可視性を記録する。画像の読み込みに加え、レタッチの描画済みキャンバスを確認してから撮影する。

**データの隔離**

Electronスモークは合成画像と一時DBを使用し、AppData・home・写真フォルダ等を一時領域へ向ける。実ユーザーの写真を入力にしない。失敗時の調査に必要な画像とDBは一時領域に残る。

配布版を検証するときは、既存の `WORLDSHOT_APPDATA_ROOT` / `WORLDSHOT_LOCALAPPDATA_ROOT` に加え、明示的な `WORLDSHOT_HOME_ROOT` でhomeと標準フォルダを一時領域へ向ける。Windowsでは `USERPROFILE` の環境変数だけではElectronのhomeが変わらず、サムネイル移行が実ユーザーのhomeを参照してしまう。新しい変数がない通常起動の保存場所は従来どおり。各スモークは継承した環境変数も自身の一時profileへ置き換える。

**この検証で保証しないもの**

固定画像と操作での回帰検証は、全編集機能の組合せ、すべての実写真、別GPU/OS、モデルの切り抜き品質を保証するものではない。配布パッケージ起動、インストーラの整合性、更新配信は別の確認項目として扱い、開発環境の検証成功だけで公開しない。確認用候補のビルドと手動確認は [リリース前の確認](./release-candidate-review-2026-09-10.md) を参照。
