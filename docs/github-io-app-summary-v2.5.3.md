# WorldShot Log 紹介サイト用 機能整理 v2.5.3

以下は、GitHub Pages などの紹介サイトへ反映するためのコピペ用整理文です。

## 今回の更新ポイント

WorldShot Log v2.5.3 では、アプリロゴを新しいデザインへ刷新し、画像編集にやわらかく淡い雰囲気を加える「エアリーホワイト」プリセットを4種類追加しました。

ニュートラル、暖色、寒色、ドリーミーの4方向から写真に合わせた仕上がりを選べます。また、画像オーバーレイを拡大・縮小できなくなっていた問題を修正し、透過素材やロゴを重ねる編集も再び直感的に行えるようになりました。

## サイト向け短文

WorldShot Log は、VRChatスクリーンショットを整理し、見返し、投稿しやすく整えるためのWindows向けアプリです。v2.5.3 ではロゴを刷新し、露出とコントラストを抑えながら透明感を加える「エアリーホワイト」プリセットを4種類追加しました。画像オーバーレイの拡大・縮小も修正し、写真に素材やロゴを重ねる仕上げがより扱いやすくなっています。元画像は上書きせず、加工後の画像を別名保存できます。

## 更新内容

- アプリアイコン、ウィンドウアイコン、ヘッダー、READMEのロゴを新しいデザインへ更新しました。
- 「エアリーホワイト1」から「エアリーホワイト4」まで、仕上がりの異なる4種類の画像加工プリセットを追加しました。
- ニュートラル、暖色、寒色、ドリーミーから写真に合う雰囲気を選べます。
- すべてのプリセットで、強度スライダーによる効果量の調整が可能です。
- 画像オーバーレイを選択枠から拡大・縮小できなくなっていた問題を修正しました。
- 日本語、英語、韓国語のプリセット表示に対応しました。

## 引き続き使える主な機能

- VRChatスクリーンショットのドラッグ&ドロップ取り込み
- 年、月、日付、ワールドごとの写真整理
- お気に入り、向き、ラベル、World名での絞り込み
- 写真詳細モーダルでの閲覧、メモ、ラベル、World情報管理
- 明るさ、露出、コントラスト、色温度、彩度などの画像補正
- RGB / HSV トーンカーブとヒストグラム表示
- 切り抜き、ズーム、回転、反転、ルーラー、三分割グリッド
- AI被写体選択、背景透過PNG保存、マスク手動修正
- ぼかし、モザイク、塗りつぶしによる目隠し加工
- 複数テキスト、フォント、縁取り、影、発光、文字間隔の調整
- 透過素材などの画像オーバーレイ管理
- 日本語、英語、韓国語の表示

## サイト向けキャッチコピー案

- ふわっと透明感。写真に合わせて選べる4つの白。
- VRChat写真を、やさしく淡い空気感へ。
- 整理から仕上げまで、思い出をもっと自分らしく。
- 写真を見返しやすく、投稿しやすく。
