# WorldShot Log 紹介サイト用 機能整理 v2.5.2

以下は、GitHub Pages などの紹介サイトへ反映するためのコピペ用整理文です。

## 今回の更新ポイント

WorldShot Log v2.5.2 では、画像編集画面の切り抜きズームや位置調整時に、テキスト、画像オーバーレイ、放射ぼかしが画像内容へ自然に追従するよう、座標処理を整理しました。

これにより、構図を拡大・調整しながら編集しても、追加したテキストや素材、ぼかし位置が Canvas 表示側に取り残されにくくなり、投稿用画像の仕上げが安定します。

## サイト向け短文

WorldShot Log は、VRChatスクリーンショットを整理し、見返し、投稿しやすく整えるためのWindows向けアプリです。v2.5.2 では画像編集の座標処理を改善し、切り抜きのズームや位置調整を行っても、テキスト、画像オーバーレイ、放射ぼかしが画像内容に追従しやすくなりました。元画像は上書きせず、加工後の画像を別名保存できます。

## 更新内容

- 画像編集画面のテキスト、画像オーバーレイ、放射ぼかしの配置基準を整理しました。
- 切り抜きのズーム、左右位置、上下位置を変更したとき、編集要素が画像内容に追従するようにしました。
- テキストと画像オーバーレイの選択枠、ドラッグ、リサイズ、スナップ処理を新しい座標基準に合わせました。
- 座標追従を確認する専用スモークテストを追加しました。

## 引き続き使える主な機能

- VRChatスクリーンショットのドラッグ&ドロップ取り込み
- 年、月、日付、ワールドごとの写真整理
- お気に入り、向き、ラベル、World名での絞り込み
- 写真詳細モーダルでの閲覧、メモ、ラベル、World情報管理
- 明るさ、露出、コントラスト、色温度、彩度などの画像補正
- RGB / HSV トーンカーブとヒストグラム表示
- 切り抜き、ズーム、回転、反転、ルーラー、三分割グリッド
- AI被写体選択、背景透過PNG保存、マスク手動修正
- ぼかし、モザイク、塗りつぶしによる目隠し加工
- 複数テキスト、フォント、縁取り、影、発光、文字間隔の調整
- 透過素材などの画像オーバーレイ管理
- 日本語、英語、韓国語の表示

## サイト向けキャッチコピー案

- 画像編集の配置が、もっと意図通りに。
- 切り抜いても、重ねた要素が画像に寄り添う。
- VRChat写真の整理と仕上げを、ひとつのアプリで。
- 思い出を見返しやすく、投稿しやすく。
