# WorldShot Log v1.3.0

写真一覧の表示速度と体感レスポンスを改善するため、計測ログ、DB取得、描画、サムネイル読み込みをまとめて最適化した更新です。

## 更新内容

- 写真一覧取得、表示前メタデータ補完、レンダラー側の初期描画にパフォーマンス計測ログを追加しました。
- 遅い処理だけが通常ログに出るようにし、必要に応じて詳細計測を有効化できるようにしました。
- 実データでの計測結果をもとに、保存済みの向き情報がある写真では一覧表示時にサムネイルや元画像を読み直さないようにしました。
- 月別、年別、World別の写真取得に使うSQLiteインデックスを追加しました。
- 写真一覧向けのDB取得で、作成日時など表示に不要な列を取得しないようにしました。
- World別写真取得でSQLを毎回組み立てず、準備済みステートメントを再利用するようにしました。
- World名のみで絞り込む場合も、全件取得後にアプリ側で絞り込まず、DB側で対象行だけ取得するようにしました。
- 大量写真表示時に一度に生成するカード数を抑え、スクロールに合わせて段階的に追加描画するようにしました。
- サムネイル画像を非同期デコードし、初期表示分だけ読み込み優先度を上げるようにしました。
- サムネイルの読み込みに失敗した場合は、壊れた画像の代わりに再生成が必要なプレースホルダーを表示するようにしました。

## 補足

- メインプロセス側は環境変数 `WORLDSHOT_PERF_LOG=1` で詳細ログを常時出せます。
- レンダラー側は開発者コンソールで `localStorage.setItem('worldshotPerfLog', '1')` を実行すると詳細ログを常時出せます。
- 既存の写真データ形式は変更していません。
