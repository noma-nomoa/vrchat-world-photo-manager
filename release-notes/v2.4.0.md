# WorldShot Log v2.4.0

WorldShot Log v2.4.0 をリリースしました。

今回の更新では、画像編集に「AI被写体選択」を追加し、被写体マスクを使った補正、ぼかし、テキスト、画像オーバーレイの加工範囲を扱えるようにしました。AI処理はPC内で実行され、画像はAI処理のために外部サーバーへ送信されません。

## 更新内容

- 画像編集に「AI被写体」セクションを追加しました。
- 同梱の軽量AI `U-2-NetP` で、初回から被写体マスクを作成できるようにしました。
- 標準AI `withoutBG Snap` を初回ダウンロード方式で追加しました。
- 高精度AI `withoutBG Focus OSS` を初回ダウンロード方式で追加しました。
- 標準AIがインストール済みの場合、「被写体を自動選択」で標準AIを優先するようにしました。
- 高精度AIは、必要な場合に「高精度で再検出」から明示的に使えるようにしました。
- Snap / Focus の複数ONNXモデルファイルを、まとめてダウンロード、検証、管理できるようにしました。
- AIモデルのダウンロード進捗に、現在処理中のモデルファイル名と総進捗を表示するようにしました。
- ダウンロードしたAIモデルはSHA256で検証し、破損や不一致がある場合は利用しないようにしました。
- ダウンロードしたAIモデルのフォルダに `LICENSE.txt`、`THIRD_PARTY_LICENSES.md`、`model.json` を保存するようにしました。
- 設定画面から、追加AIモデルの状態、容量、ライセンス、保存場所、削除を確認できるようにしました。
- BiRefNet_lite / BEN2 / BiRefNet 系モデルは、ライセンス確認の結果、推奨構成から外しました。
- 既にローカルに残っている旧AIモデルは「利用停止中の旧モデル」として表示し、削除できるようにしました。
- 被写体マスクを、補正、背景ぼかし、テキスト、画像オーバーレイの適用範囲に使えるようにしました。
- 「マスクを表示」「マスク反転」を、アプリ内の他UIと揃ったボタン表示に変更しました。
- テキスト追加と画像オーバーレイの適用範囲から、分かりにくかった「被写体の後ろ」を削除しました。
- 画像オーバーレイの前後移動、削除、合成方法の反映まわりを調整しました。
- AI被写体選択とモデル管理まわりの表示を英語・韓国語UIにも追加しました。
- AIモデルの利用状況とライセンス確認内容を `THIRD_PARTY_NOTICES.md` と `docs/ai-model-license-review.md` に整理しました。

## 補足

- AI被写体選択はPC内で実行されます。withoutBG のクラウドAPIは使用しません。
- 画像はAI処理のために外部サーバーへ送信されません。
- 標準AIと高精度AIはアプリ本体には同梱せず、必要な場合だけ初回ダウンロードします。
- 高精度AIは標準AIより処理時間やメモリ使用量が大きくなる場合があります。
- 元画像はこれまで通り上書きされません。画像編集後は別名保存されます。
- Windows 配布物は `out/make/squirrel.windows/x64/` に生成されます。
