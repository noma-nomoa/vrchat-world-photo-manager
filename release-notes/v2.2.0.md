# WorldShot Log v2.2.0

WorldShot Log v2.2.0 をリリースしました。

今回のアップデートでは、日本語に加えて英語・韓国語の表示に対応しました。設定画面から言語を切り替えられるようになり、写真一覧、カード、ラベル、画像編集まわりの主要なUIを各言語で使いやすく調整しています。

## 更新内容

- 設定画面に「言語設定」を追加しました。
- 日本語 / 英語 / 韓国語の切り替えに対応しました。
- 写真一覧、検索、フィルター、カードモーダル、ラベル編集、画像編集画面の文言を英語・韓国語へ翻訳しました。
- ワールド名を取得できなかった場合の表示や、ラベルが存在しない月の案内など、残っていた日本語表示を翻訳対象に含めました。
- 韓国語表示時のみ、設定画面で韓国語向けフォントを選べるようにしました。
  - Noto Sans KR
  - IBM Plex Sans KR
  - Dongle
  - Gaegu
  - Gowun Dodum
- 画像編集のテキスト追加機能に、韓国語・日本語・英字向けフォントを追加しました。
- 画像編集のフォント選択をアルファベット順に整理し、候補が多い場合もスクロールして選べるようにしました。
- 韓国語フォント選択時の設定画面で、ボタンや説明文のサイズ感が崩れにくいよう調整しました。
- 画像編集画面の一部入力欄やプルダウンのサイズを調整し、英語・韓国語表示でも不自然に広がりにくくしました。

## 補足

- 元画像はこれまで通り上書きされません。画像編集後は別名保存されます。
- Dongle や Gaegu などの装飾寄りフォントは、日本語を含む文章では表示の見え方が通常フォントと異なる場合があります。
- Windows 配布物は `out/make/squirrel.windows/x64/` に生成されます。
