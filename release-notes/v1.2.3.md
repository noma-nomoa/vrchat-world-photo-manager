# WorldShot Log v1.2.3

状態チェック結果の活用と、安全なメンテナンス操作を強化した更新です。

## 更新内容

- 状態チェック結果をカテゴリ別に表示できるようにしました。
- 「元画像なし」「サムネイルなし」「World情報未取得」「Worldメタデータ要確認」の該当写真だけを抽出できます。
- サムネイルが欠損している写真だけを対象に、サムネイルを再生成できるようにしました。
- Worldメタデータ要確認に該当する写真だけを対象に、Worldメタデータを再取得できるようにしました。
- バックアップから復元する前に、現在のアプリデータを自動バックアップするようにしました。
- DB初期化の前に、現在のアプリデータを自動バックアップするようにしました。
- 状態チェック時のファイル存在確認とWorldメタデータ確認を共通化し、カテゴリ抽出と修復処理で同じ判定結果を使うようにしました。

## 補足

- 自動バックアップはアプリデータ内の `backups` フォルダへJSON形式で保存されます。
- 欠損サムネイルの再生成では、元画像が見つからない写真は失敗として扱われます。
- Worldメタデータ要確認の再取得は、該当写真に含まれるWorld ID単位で重複を省いて実行します。
