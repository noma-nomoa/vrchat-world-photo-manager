# WorldShot Log v2.2.1

WorldShot Log v2.2.1 をリリースしました。

今回の更新では、英語・韓国語表示の細かな品質改善と、既存ユーザーのデータをより安全に扱うための安定化を行いました。あわせて、リリース前に翻訳・画面崩れ・データ互換を確認しやすい検証スクリプトを追加しています。

## 更新内容

- 韓国語表示の「연월」を、より自然な「날짜」に変更しました。
- 韓国語の一部表現を見直し、日付一覧や写真数順の表示を調整しました。
- 言語選択ボタンの表示を、どの言語でも `日本語` / `English` / `한국어` になるよう統一しました。
- 画像編集のテキスト追加で、最近使用したフォントの履歴を最新5件までにしました。
- カードの時刻不明表示で文字化けしていた文言を修正しました。
- 古いDBから起動する場合に、追加カラムより先にインデックス作成が走って失敗する可能性があったため、DB初期化時の移行順序を修正しました。
- 翻訳漏れを検出する `audit:i18n` を追加しました。
- 日英韓の主要画面を撮影し、日本語残りや表示はみ出しを確認する `capture:ui` を追加しました。
- 古いDB形状からの移行、バックアップ、リセット、復元を確認する `smoke:data` を追加しました。
- パッケージ済みアプリを隔離データ領域で起動確認する `smoke:packaged` を追加しました。

## 補足

- 元画像はこれまで通り上書きされません。画像編集後は別名保存されます。
- 今回の更新では、既存データを消す処理は追加していません。
- Windows 配布物は `out/make/squirrel.windows/x64/` に生成されます。
