# WorldShot Log v3.0.1

WorldShot Log v3.0.1 をリリースしました。

v3.0.0 で追加したデザインのうち、ノワール・チョコミント・ソーダで、お気に入りの星と選択のチェックが見えなくなる問題を修正しました。v3.0.0 の更新内容とあわせてご案内します。

## 更新内容

- デザインを5種類追加しました。「設定 > デザイン」で、トランジット・ランタン・ノワール・チョコミント・ソーダに切り替えられます。
- 撮影したワールドをカードで見わたせる「ワールド一覧」を追加しました。World名での検索と、枚数順・名前順・日付順の並び替えができます。
- 起動時のデザインが「ランタン」に変わります。これまでの見た目には、「設定 > デザイン」の「従来のデザイン」で戻せます。
- ノワール・チョコミント・ソーダで、お気に入りにした写真の星と、選択モードのチェックが見えなくなる問題を修正しました。

### v3.0.1 での修正

- ノワール・チョコミント・ソーダで、写真をお気に入りにすると、写真の右上の星が見えなくなる問題を修正しました。お気に入りの登録そのものは正しく行われていて、写真の詳細画面では正しく表示されていました。
- 同じ3つのデザインで、選択モードで選んだ写真のチェックが見えなくなる問題を修正しました。
- トランジット・ランタン・従来のデザインには、この問題はありません。

### v3.0.0 の更新内容

- デザイン、ワールド一覧、お知らせ、配布サイズの削減（インストーラーを約235MBから約173MBへ）などの詳しい内容は、[v3.0.0 のリリースノート](https://github.com/noma-nomoa/vrchat-world-photo-manager/releases/tag/v3.0.0)をご覧ください。

## 補足

- 既存DBを引き続き読み込めます。登録済み写真、お気に入り、メモ、ラベルなどの情報を保持します。
- v3.0.0 でお気に入りにした写真は、そのままお気に入りとして残っています。更新すると星が表示されます。
- 起動時のデザインが「ランタン」になるのは、まだデザインを選んでいない場合です。一度選んだデザインは保存されます。
- レタッチは従来どおり別名で保存し、元画像を上書きしません。
