# WorldShot Log v1.2.2 Release Notes

WorldShot Log v1.2.2 をリリースしました。

## 更新内容

- 設定画面にデータ管理セクションを追加しました。
- ラベル、メモ、お気に入り、World情報、更新対象フォルダを含むバックアップ作成に対応しました。
- バックアップJSONからの復元に対応しました。
- 写真一覧のCSV / JSONエクスポートに対応しました。
- 元画像、サムネイル、World情報、Worldメタデータの状態チェックに対応しました。
- Worldメタデータ要確認の写真だけを抽出して一覧表示できるようにしました。
