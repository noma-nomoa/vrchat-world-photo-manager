# WorldShot Log v2.3.0

WorldShot Log v2.3.0 をリリースしました。

今回の更新では、画像編集に透過画像などを重ねられる「画像オーバーレイ」を追加しました。自分で用意したPNGやWebPなどを管理素材として取り込み、複数レイヤーとして配置、調整、保存できます。

## 更新内容

- 画像編集に「画像オーバーレイ」を追加しました。
- PNG / JPG / WebP 画像をオーバーレイ素材として取り込めるようにしました。
- 取り込んだオーバーレイ素材はアプリの管理フォルダへコピーされ、次回以降も再利用できます。
- 管理素材をアプリ上から削除できるようにしました。
- 複数の画像オーバーレイを同時に追加できるようにしました。
- オーバーレイごとに透明度を調整できるようにしました。
- オーバーレイごとに合成方法を選べるようにしました。
  - 標準合成
  - 乗算
  - スクリーン
  - オーバーレイ
  - ソフトライト
  - ハードライト
  - 比較(暗)
  - 比較(明)
- オーバーレイの前後順を変更できるようにしました。
- オーバーレイをドラッグで移動できるようにしました。
- オーバーレイ右下のハンドルでサイズ変更できるようにしました。
- サイズ変更時、Shift キーを押しながら操作すると比率を保てるようにしました。
- 三分割グリッドとルーラーガイドに、オーバーレイの中心や端が軽く吸着するようにしました。
- 画像オーバーレイ関連の表示を英語・韓国語UIにも追加しました。

## 補足

- 元画像はこれまで通り上書きされません。画像編集後は別名保存されます。
- 取り込んだオーバーレイ素材は、アプリのユーザーデータ内にある `photo-editor-overlays` 管理フォルダへコピーされます。
- 管理素材を削除すると、現在の編集で同じ素材を使っている画像レイヤーも外れます。
- Windows 配布物は `out/make/squirrel.windows/x64/` に生成されます。
