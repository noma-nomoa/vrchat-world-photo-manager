# WorldShot Log v3.0.0

WorldShot Log v3.0.0 をリリースしました。

今回の更新では、デザインを5種類追加し、撮影したワールドをカードで見わたせる「ワールド一覧」を追加しました。あわせて配布物の中身を整理し、インストーラーのサイズを約235MBから約173MBへ削減しています。

## 更新内容

- デザインを5種類追加しました。「設定 > デザイン」で、トランジット・ランタン・ノワール・チョコミント・ソーダに切り替えられます。
- 撮影したワールドをカードで見わたせる「ワールド一覧」を追加しました。World名での検索と、枚数順・名前順・日付順の並び替えができます。
- 起動時のデザインが「ランタン」に変わります。これまでの見た目には、「設定 > デザイン」の「従来のデザイン」で戻せます。
- インストーラーのサイズを約235MBから約173MBへ削減しました。

### デザイン

- 追加したデザインは次の5種類です。
  - トランジット: 黄色い帯と黒い作業面
  - ランタン: オレンジの帯と深緑の作業面
  - ノワール: 明るいグレーの帯と黒い作業面
  - チョコミント: ミントの帯とチョコレート色の作業面
  - ソーダ: 水色の帯と深い青の作業面
- 追加したデザインはダーク表示専用です。ライト表示は、従来のデザインで引き続き使えます。
- 更新後の最初の起動で、追加したデザインとワールド一覧を紹介するお知らせを表示します。お知らせの中のボタンで、デザインをその場で試せます。あとから「設定 > デザイン」の「v3.0.0 のお知らせを見る」でも開けます。
- アプリアイコンを、アプリ内のロゴと同じ絵にそろえました。タスクバーなどの小さい表示でも輪郭がはっきり見えるよう、大きさごとの絵を用意しています。

### ワールド一覧

- サイドバーの「ワールド一覧」を押すと、撮影したワールドがカードで並びます。カードには、ワールドの画像・作者名・枚数・最後に撮った日を表示します。
- カードを押すと、そのワールドの写真一覧を開きます。マウスの戻るボタンを押すと、ワールド一覧の元の位置に戻ります。
- 並び替えに「日付順」を追加しました。最後に撮った日が新しいワールドから並びます。「撮影枚数順」は「枚数順」に名前を変えました。
- 上部の検索欄で、World名からカードを絞り込めます。
- ワールドの画像は、VRChat から一度だけ取得してPC内に保存します。次回からは通信せずに表示します。
- すでに取り込み済みのワールドの画像は、「設定 > メンテナンス」の「ワールドのサムネイルを取得」でまとめて取得できます。

### 配布サイズの削減

- AI切り抜きで使う実行ファイル（ONNX Runtime）が、配布物の中に重複して含まれていた問題を修正しました。
- 実際には読み込まれない実行方式のファイルを同梱対象から外しました。AI切り抜きは従来と同じ方式で動作します。
- インストール後のフォルダーサイズも、約666MBから約412MBへ減りました。
- アプリの動作に不要な開発用の資料とログを、配布物に含めないようにしました。

### 内部処理

- 配布版の自動チェックを拡充し、不要なファイルが再び配布物に含まれた場合に検出できるようにしました。

## 補足

- 既存DBを引き続き読み込めます。登録済み写真、お気に入り、メモ、ラベルなどの情報を保持します。
- 起動時のデザインが「ランタン」になるのは、まだデザインを選んでいない場合です。これまでのバージョンにはデザインの選択がなかったため、更新した方は全員が対象になります。一度選んだデザインは保存されます。
- チョコミントとソーダの丸い書体は、インターネットから読み込みます。オフラインのときは標準の書体で表示します。
- ワールドの画像を取得できるのは、VRChat で画像が公開されているワールドです。取得できないワールドは、そのワールドで最後に撮った写真をカードに表示します。
- ワールドの画像をまとめて取得するときは、ワールドの数が多いほど時間がかかります。取得中は、ほかの操作ができません。
- 同梱の軽量AIモデルは、これまでどおりオフラインで利用できます。
- レタッチは従来どおり別名で保存し、元画像を上書きしません。既存の色調整・プリセットの仕上がりを維持しています。
- アプリ内の更新機能で配信するファイルも、同様に小さくなります。
