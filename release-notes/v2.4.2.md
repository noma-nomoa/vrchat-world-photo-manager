# WorldShot Log v2.4.2

WorldShot Log v2.4.2 をリリースしました。

今回の更新では、アップデート適用後の初回起動時に、主な更新内容を確認できるモーダルを表示するようにしました。v2.4.1 で追加した画像編集まわりの更新内容も、今回に限りあわせて表示されます。

## 更新内容

- アップデート適用後の初回起動時に、主な更新内容をOKボタン付きモーダルで1回だけ表示するようにしました。
- v2.4.1の内容として、トリミングに「アバターサムネイル」プリセットを追加しました。
- v2.4.1の内容として、AI被写体選択のマスクを使った背景透過PNG保存に対応しました。
- v2.4.1の内容として、フォント選択の見やすさ改善、画像オーバーレイ、解像度判定などの修正を含めています。
- 更新前の確認モーダルには詳細な更新内容を出さず、更新後の初回案内にまとめました。
- 新規インストール時には更新後案内を表示せず、既存ユーザーのアップデート後だけ表示するようにしました。

## 補足

- 更新内容は GitHub Release 本文の `## 更新内容` から最大4件を表示します。
- 今回は v2.4.1 の更新内容をユーザーに知らせるため、先頭4件に v2.4.1 の主要項目を含めています。
- 元画像や管理データの保存先は変更していません。
- Windows 配布物は `out/make/squirrel.windows/x64/` に生成されます。
