# WorldShot Log v2.1.0

WorldShot Log v2.1.0 をリリースしました。

今回の更新では、画像編集画面の操作感を中心に改善しました。テキスト追加、目隠し加工、切り抜き・構図調整をより直感的に扱えるようにし、プレビュー操作中のもたつきも軽減しています。

## 更新内容

- 画像編集画面に、ルーラーからドラッグして配置できる補助線を追加しました。
- 作成済みの補助線を、後からドラッグして位置調整できるようにしました。
- テキストボックス、目隠し加工の四角・丸・フリーハンド図形が、中央線や補助線に吸着するようにしました。
- テキストボックスは中心だけでなく、枠の上下左右でも吸着するようにしました。
- 吸着判定をより狭く調整し、線にかなり近づいた時だけ吸い付く挙動にしました。
- テキストをプレビュー上で移動する際の再描画処理を軽量化し、操作中のもたつきを軽減しました。
- ウィンドウサイズ変更後も、テキストの見た目の大きさがプレビューと書き出し結果でずれにくいようにしました。
- テキスト移動中に、補正処理を毎回走らせず、テキストと操作枠だけを再描画するようにしました。

## 補足

- 元画像は上書きされません。編集後の画像はこれまで通り別名で保存されます。
- ルーラー、補助線、吸着ガイドは編集時の補助表示です。書き出し画像には含まれません。
- Windows 配布物は `out/make/squirrel.windows/x64/` に生成されます。
