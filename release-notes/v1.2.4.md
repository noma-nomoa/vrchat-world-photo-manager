# WorldShot Log v1.2.4

写真一覧表示の待ち時間を減らすため、表示前のメタデータ補完処理を軽量化した更新です。

## 更新内容

- 写真一覧を表示する前のサムネイル/元画像の存在確認を、同じ処理内で再利用するようにしました。
- 写真の向き補正とプリントノート補完の結果をセッション内でキャッシュし、同じ写真を再表示したときの再確認を減らしました。
- 表示前メタデータ補完の並列数を制御し、大量の写真を開くときにディスクアクセスが一気に集中しにくいようにしました。
- バックアップ復元やDB初期化後は、表示準備キャッシュをクリアして復元後のデータを正しく反映するようにしました。

## 補足

- 画像ファイル自体や登録データの形式は変更していません。
- キャッシュはアプリ起動中だけ使われ、アプリを終了すると破棄されます。
