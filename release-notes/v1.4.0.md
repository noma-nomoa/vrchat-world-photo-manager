# WorldShot Log v1.4.0

日付ごとの写真移動と大量写真月の操作性を改善するため、サイドメニューの日付ジャンプ、解像度ラベル拡張、キーボード操作改善を追加した更新です。

## 更新内容

- 画像解像度の判定ラベルを `HD`、`FHD`、`QHD`、`4K`、`8K` に拡張しました。
- サイドメニューで月を開くと、撮影日ごとの日付一覧を表示できるようにしました。
- 日付をクリックすると、該当する日付グループへ直接ジャンプできるようにしました。
- 日付ジャンプ後、現在表示している日付がサイドメニュー上でも分かるようにしました。
- 新しい順/古い順の切り替え時、年/月は新しい順のまま、日付だけが並び替わるようにしました。
- サイドメニューと写真一覧を別々にスクロールできるようにし、日付一覧が長い月でも操作しやすくしました。
- 大量写真月での日付ジャンプ時に、一度に大量のカードを生成せず、段階的に描画するようにしました。
- スクロール中の現在日付判定で、DOM全体を毎回探さず、描画済みグループのキャッシュを使うようにしました。
- 日付ジャンプ後にキーボード操作をした場合、月の先頭ではなくジャンプ先の日付グループ内の先頭画像から操作できるようにしました。
- 日付ジャンプ時のハイライト演出を改善し、連続ジャンプ時にも毎回アニメーションするようにしました。
- 日付ジャンプ演出の終了時に一瞬点滅しないようにしました。

## 補足

- 既存の写真データ形式は変更していません。
- 今回の改善は主に月別一覧とサイドメニューの日付操作に関するものです。
- Windows 配布物は `out/make/squirrel.windows/x64/` に生成されます。
