# WorldShot Log v2.5.0

WorldShot Log v2.5.0 をリリースしました。

今回の更新では、AI被写体選択で作成したマスクを手動で整えやすくし、画像編集画面のズーム時の操作感や、テキスト・画像オーバーレイの選択表示を改善しました。あわせて、画像オーバーレイ追加時の比率崩れなどを修正しています。

## 更新内容

- AI被写体選択のマスクを、ブラシで「修正する」「消す」操作ができるようにしました。
- ブラシサイズ、濃度、スポイト機能を追加し、マスクの境界をより自然に調整できるようにしました。
- 画像編集Canvas上のホイール拡大と中ボタンドラッグ移動を改善し、細部を確認しながら編集しやすくしました。
- テキスト追加・画像オーバーレイの選択枠を見やすくし、ズーム時にも位置がずれにくい表示にしました。
- 画像オーバーレイ追加時、素材本来の縦横比を保った状態で配置されるようにしました。
- マスク修正ブラシのカーソル表示をCSSベースに変更し、小さいブラシサイズでも輪郭を確認しやすくしました。
- AI被写体選択まわりの処理を分割し、今後の画像編集機能追加に備えて整理しました。
- マスク修正まわりのスモークテストを追加しました。

## 補足

- 元画像や管理データの保存先は変更していません。
- 既存のAIモデル保存先やモデル管理の仕様は変更していません。
- Windows 配布物は `out/make/squirrel.windows/x64/` に生成されます。
