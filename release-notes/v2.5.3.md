# WorldShot Log v2.5.3

WorldShot Log v2.5.3 をリリースしました。

今回の更新では、アプリのロゴを刷新し、画像編集にやわらかく淡い仕上がりを加える「エアリーホワイト」プリセットを4種類追加しました。画像オーバーレイを拡大・縮小できなくなっていた問題も修正しています。

## 更新内容

### エアリーホワイトプリセット

- 「エアリーホワイト1」: 色味を大きく変えず、軽く透明感を加えるニュートラルな仕上がりです。
- 「エアリーホワイト2」: 暖かさと淡いピンクを加えた、やさしい仕上がりです。
- 「エアリーホワイト3」: 青紫をほのかに加えた、涼しく透明感のある仕上がりです。
- 「エアリーホワイト4」: フェード感とやわらかさを強めた、最もドリーミーな仕上がりです。
- 4種類とも露出とコントラストを抑え、ホワイトを持ち上げながら、明瞭度とテクスチャを下げる方向で調整しています。
- プリセット名を日本語、英語、韓国語で表示できるようにしました。

### 画像オーバーレイ

- 画像オーバーレイの選択枠を操作しても拡大・縮小できなくなっていた問題を修正しました。
- 切り抜きのズームや位置調整に追従する、画像基準の座標処理はそのまま維持しています。
- オーバーレイのリサイズを確認する回帰テストを追加しました。

### デザイン

- アプリアイコン、ウィンドウアイコン、ヘッダー、READMEで使用するロゴを新しいデザインへ更新しました。
- 今後の調整に利用できるロゴのSVGデータとプレビュー画像を同梱しました。

## 補足

- プリセット適用後も「強度」スライダーで効果量を調整できます。
- 元画像、登録済み写真データ、更新対象フォルダの保存内容は変更していません。
- Windows 配布物は `out/make/squirrel.windows/x64/` に生成されます。
