# WorldShot Log v2.0.0

WorldShot Log に、VRChatスクリーンショットをアプリ内で整えられる画像編集機能を追加した大型アップデートです。

元画像は上書きせず、加工後の画像を別名で保存できます。投稿用、サムネイル用、Booth掲載用など、スクリーンショットをその場で仕上げやすくしました。

## 更新内容

- 写真詳細から起動できる画像編集モーダルを追加しました。
- 明るさ、露出、コントラスト、ハイライト、シャドウ、ホワイト、ブラック、色温度、色合い、彩度、自然な彩度、明瞭度、テクスチャ、フェード、粒子、ビネットなどの補正を追加しました。
- スマート自動補正と学習補正を追加し、補正の強さを調整できるようにしました。
- RGB/HSVのトーンカーブを追加し、全体チャンネルと個別チャンネルを5点カーブで調整できるようにしました。
- トーンカーブの背景にヒストグラムを表示し、明るさや色の分布を見ながら調整できるようにしました。
- 補正、切り抜き、プリセット、ぼかし、目隠し加工などをアコーディオン化し、項目が増えても操作しやすい構成にしました。
- プリセットを拡充し、VRChat向け、夜景、ネオン、ふんわり、フィルム、高コントラスト、青系、ピンク系などの雰囲気をワンクリックで適用できるようにしました。
- ユーザーが現在の加工状態に名前を付けてプリセット保存できるようにしました。
- 切り抜きにオリジナル、1:1、16:9、9:16、5:4、4:5、3:2、2:3、VRCギャラリー用、絵文字・ステッカー用の比率を追加しました。
- 90度回転、自由回転、左右反転、上下反転、ズーム、位置調整を追加しました。
- ルーラーと三分割グリッドを追加し、構図を確認しながら切り抜けるようにしました。
- ぼかし機能を追加し、全体ぼかしと放射ぼかしを切り替えられるようにしました。
- 放射ぼかしは画像上の円を操作して、ぼかしの中心やなだらかさを直感的に調整できるようにしました。
- 目隠し加工を追加し、ぼかし、モザイク、塗りつぶしでユーザー名、チャット欄、UIなどを隠せるようにしました。
- 目隠し範囲は四角、円、フリーハンドで選択でき、確定前に移動、拡大縮小、回転を調整できるようにしました。
- テキスト追加機能を追加し、複数テキスト、フォント、太さ、文字色、縁取り、文字間隔、回転を調整できるようにしました。
- テキスト追加のプレビューと書き出し結果で文字サイズが大きくずれないようにし、画面上で確認した大きさに近い状態で保存できるようにしました。
- Google Fonts系の日本語/装飾フォントを追加し、最近使ったフォントを選びやすくしました。
- Undo/Redo、全体リセット、比較表示、別名で保存を画像編集画面の上部に追加しました。
- プレビュー描画、切り抜き移動、スライダー操作、ぼかしや目隠し加工の操作感を改善しました。

## 補足

- 元画像は上書きしません。編集後の画像は別名で保存されます。
- 編集後の保存では、可能な範囲で元画像のメタ情報を引き継ぎます。
- 画像編集機能はVRChatスクリーンショットの軽いレタッチと投稿準備を目的としており、本格的な写真編集ソフトの完全互換ではありません。
- Windows配布物は `out/make/squirrel.windows/x64/` に生成されます。
