# WorldShot Log v2.5.1

WorldShot Log v2.5.1 をリリースしました。

今回の更新では、設定画面から更新対象フォルダを削除する際、確認モーダルが設定画面の背面に表示されて操作できない問題を修正しました。

## 更新内容

- 更新対象フォルダの削除確認モーダルが、設定画面より前面に表示されるように修正しました。
- 設定画面から開く共有確認モーダルの表示階層を調整し、確認・キャンセルボタンを操作できるようにしました。

## 補足

- 元画像、登録済み写真データ、更新対象フォルダの保存内容は変更していません。
- Windows 配布物は `out/make/squirrel.windows/x64/` に生成されます。
