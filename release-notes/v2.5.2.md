# WorldShot Log v2.5.2

WorldShot Log v2.5.2 をリリースしました。

今回の更新では、画像編集画面で切り抜きのズームや位置調整を行ったとき、テキスト、画像オーバーレイ、放射ぼかしが画像内容に追従するように座標処理を整理しました。

## 更新内容

- テキスト追加、画像オーバーレイ、放射ぼかしの配置基準を画像側の座標として扱うようにしました。
- 切り抜きのズーム、左右位置、上下位置を変更したとき、編集要素が Canvas 表示側ではなく画像内容に追従するようにしました。
- テキストと画像オーバーレイの選択枠、ドラッグ、リサイズ、スナップ処理を新しい座標基準に合わせました。
- 座標追従の専用スモークテスト `smoke:coordinates` を追加しました。
- 既存のマスクブラシスモークを新しい座標基準に合わせて更新しました。

## 補足

- 元画像、登録済み写真データ、更新対象フォルダの保存内容は変更していません。
- Windows 配布物は `out/make/squirrel.windows/x64/` に生成されます。
