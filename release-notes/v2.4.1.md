# WorldShot Log v2.4.1

WorldShot Log v2.4.1 をリリースしました。

今回の更新では、画像編集の使い勝手を改善し、AI被写体選択を使った背景透過保存、アバター向けトリミング、テキストフォント選択の見やすさを追加しました。あわせて、画像オーバーレイや保存後の解像度表示まわりの不具合を修正しています。

## 更新内容

- トリミングに「アバターサムネイル」プリセットを追加しました。
- AI被写体選択のマスクを使い、背景を透過したPNG画像を保存できるようにしました。
- テキスト追加のフォント選択で、各フォント名を実際のフォント表示で確認できるようにしました。
- 画像オーバーレイや解像度判定など、軽微なバグを修正しました。
- 「AI被写体」セクション名を「AI被写体選択」に変更しました。
- VRCギャラリー、絵文字・ステッカー、アバターサムネイルなど、解像度を指定するトリミングプリセットの保存時リサイズを調整しました。
- 編集後画像の取り込み時、ファイル名に元画像の解像度が含まれていても、実際の画像サイズを優先して解像度ラベルを判定するようにしました。
- 画像オーバーレイの適用範囲が「被写体のみ」「背景のみ」の場合でも、合成方法が反映されるようにしました。
- 起動時のアップデート通知に、GitHub Release本文から主な更新内容を表示できるようにしました。

## 補足

- 背景透過保存はAI被写体選択のマスク作成後に使用できます。
- 背景透過保存は透明度を保持するためPNG形式で保存されます。
- 元画像はこれまで通り上書きされません。画像編集後は別名保存されます。
- Windows 配布物は `out/make/squirrel.windows/x64/` に生成されます。
